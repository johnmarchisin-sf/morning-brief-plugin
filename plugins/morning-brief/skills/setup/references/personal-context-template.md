# Personal Context Template

This is the structure for `about-me.md`, a general personal-context file created at the
root of the user's working folder during first-time provisioning. It is intentionally
broader than the morning brief: other skills and future sessions can read it too. Fill
each field from the user's onboarding answers; leave a short placeholder if unknown.

```
# About Me

_Last updated: {YYYY-MM-DD}. Edit this any time; Claude reads it to understand you._

## Identity
- Name / what to call me: {name}
- Location & timezone: {city, timezone}
- Primary email: {email}

## Current situation
- Role / company, or status: {role at company | between roles / job searching | student | ...}
- What I am focused on right now: {the main thing}
- Other things worth tracking: {secondary focuses}

## How I like to work
- Work style: {deep focus AM | admin first | meeting-driven | flexible}
- Communication preferences: {tone, length, formatting notes, e.g. "concise, no dashes"}

## People and priorities
- Important people / senders: {names, addresses, domains}
- What counts as urgent for me: {top priority signals}

## Tools I use
- Email: {Gmail | Outlook | ...}
- Calendar: {Google Calendar | Outlook | none}
- Chat: {Slack | Teams | none}
- Other: {anything else relevant}
```
